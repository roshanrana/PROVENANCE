Six distinct logprob vectors across 32 identical requests with invariance off.
**One** with it on. Same prompt, same seed, same temperature, same card, same
session.

That is the whole argument of ATTEST in two rows: the default deployment posture
cannot reproduce its own outputs, and a documented engine flag fixes it.

## How the two arms were kept honest

`VLLM_BATCH_INVARIANT` is read at vLLM **import time**, so one engine process
cannot serve both arms. The run is therefore two passes over one run-id:

```
LAUNCH_ENGINE_BI=0 → pass A → cells_done 1 of 2, PASS_A_SKIPS=1
LAUNCH_ENGINE_BI=1 → pass B (--resume) → cells_done 2 of 2
```

**`PASS_A_SKIPS=1` is the line that makes this result trustworthy.** The driver
refused to run the invariance-on cell against the invariance-off engine, left it
PENDING, and the second pass picked it up once the right engine was live.

The immediately preceding H100 run reported *"invariance did not eliminate
divergence"* — 6 unique off, **7** unique on. That was an artifact: the guard
read `/_stub/resolved_config`, an endpoint that exists only on the test stub, so
against real vLLM it returned "could not compare" and both arms ran against the
invariance-off engine. `PASS_A_SKIPS=0` was the tell, along with a 32-trial cell
finishing in zero seconds.

The two runs agree exactly on the arm that was genuinely measured both times
(`c0000`: 6 unique), and differ only on the arm that was mislabelled the first
time (7 → 1). That contrast is the strongest available evidence that the guard
fix is what changed, and not the hardware.

The guard now **fails closed**: an engine whose invariance state cannot be read
is refused, not assumed to agree.

## What this does not establish

- **No cost number yet.** Both passes completed in ~1 second of wall clock at
  this size, which is far too coarse to measure what determinism costs. The
  harness records no per-request latency; that is the gap to close before any
  cost-of-determinism figure can be published.
- **One configuration.** Concurrency 16, 64 max tokens, one model, one card. The
  rate of divergence and its dependence on batch shape need the fuller ladder.
- **No confidence interval.** Six digests out of 32 trials is a presence result.
- **Nothing about SGLang**, and nothing about the caching × determinism 2×2
  (A-03) — the reason the H100 was chosen is that SGLang's FA3 backend is
  Hopper-only, and that arm has not been run.
- **Prefix caching was off in both arms**, so this says nothing about the
  interaction that D-06 pins off and ADR-009 exists to decompose.
