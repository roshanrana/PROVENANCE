Verifiable and tenant-isolated LLM inference for regulated environments. Two workstreams:
**ATTEST** (inference reproducibility as a model-risk control) and **BARRIER** (KV-cache
prefix locality as a cross-tenant leak, and its mitigation).

> This file is loaded into **every** subagent's context. Keep it short and rule-dense.
> Background belongs in `docs/design/`, not here.

## Start here, every session

`STATE.md` is the single source of truth for where the project is. Read it first. Never
begin with a repo-wide crawl or `git log` archaeology — `STATE.md` exists so that is
never necessary.

## Non-negotiables

- **Stay in scope.** A task may touch only the files its pack lists. Blocked beats
  improvised.
- **Contracts in `docs/design/03-lld.md` §4 are frozen.** Deviating is a plan change, not a
  judgment call. Stop and report.
- **`make check` must be green** before any task is marked done.
- **Two strikes.** A task failing validation twice stops, is marked `blocked`, and returns
  to the orchestrator. No third attempt.
- **`common/` is a leaf** — it must never import from `attest/` or `barrier/`.
- **Never log** private keys, tenant API keys, the EPP salt secret, or derived salts. A
  derived salt in a log is a forgeable credential.
- **Fail fast.** This is measurement code. A silently degraded run produces a plausible
  wrong number, which is the worst outcome available to a project whose entire value is
  credibility.

## Evidence discipline

Every number that appears in the README or a writeup must trace to committed raw output
plus the exact command and git SHA. Figures are regenerated by script, never hand-edited.
`bench/results/<run-id>/` is immutable once written — a re-run creates a new run-id.

Negative results are published with the same rigour as positive ones. An experiment that
fails to show the expected effect is a finding, not an embarrassment.
